# Diagramas de Arquitetura

Os diagramas oficiais do Virtual Employee Platform são mantidos no **Eraser**, enquanto as decisões, regras e especificações textuais são versionadas neste repositório GitHub.

## Workspace oficial

[Virtual Employee Platform — Eraser Architecture Workspace](https://app.eraser.io/workspace/UcBRZVFG8H5U6A3qDZwZ)

## Organização dos artefatos

O workspace é a referência visual para a arquitetura do produto e já contém as visões:

1. **Macro Architecture** — visão executiva dos grandes blocos da plataforma.
2. **High-Level Architecture** — visão técnica detalhada dos canais, módulos, infraestrutura e provedores externos.

A evolução planejada do workspace inclui:

3. C4 System Context
4. C4 Container
5. Module Architecture
6. Scheduling Domain
7. Conversation / AI Flow
8. Payment Flow
9. Refund Flow
10. SaaS Billing Flow
11. Data Model / ERD
12. Deployment Architecture

## Regra de documentação

- **GitHub:** fonte de verdade para decisões arquiteturais, ADRs, regras, contratos e documentação textual versionada.
- **Eraser:** fonte visual para diagramas e representação da arquitetura.

Os diagramas devem permanecer alinhados aos documentos em `docs/architecture/` e aos ADRs em `docs/architecture/adr/`.
