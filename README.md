# virtual-employee-platform
Plataforma SaaS Multi-Tenant de funcionário virtual com atendimento via WhatsApp, agendamento, pagamentos, IA e gestão para pequenos negócios de serviços.  Se quiser algo mais técnico:  SaaS Multi-Tenant em .NET para automação de atendimento, agendamento e pagamentos via WhatsApp, com IA, arquitetura modular e PWA mobile-first.
